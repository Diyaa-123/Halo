Phase 3 · Custom Cursor

Magnetic dual-ring cursor system

~1 hr
Gate check
Inner dot snaps exactly to cursor. Outer ring lags visibly behind. Ring expands on hovering a button. Default cursor invisible.
CustomCursor.jsx — two divs: #cursor-dot (8px filled teal circle) + #cursor-ring (40px border-only ring). Both position:fixed, pointer-events:none, z-index:9999.components/CustomCursor.jsx
rAF lerp loop: dot teleports to mouseX/Y via transform:translate(). Ring uses lerp: ringX += (mouseX - ringX) * 0.1 each frame. Fire only after first mousemove event.components/CustomCursor.jsx
Hover expansion: add data-cursor="expand" to all buttons/nav links. Listen for mouseenter/leave globally, toggle ring to 70px + color shift via CSS class .cursor-expanded.components/CustomCursor.jsx

Phase 5 · Scroll-Jacking

Full-viewport panel transitions — the hardest part

~3 hrs
Gate check — the big one
Scrolling moves between panels with smooth GSAP transition. Right-edge pills update. No double-fire on fast scroll. Mobile falls back to normal scroll.
useScrollSection.js hook: track activePanel (0–4), expose goTo(n). Add 900ms cooldown flag isTransitioning to block rapid-fire.hooks/useScrollSection.js
Intercept wheel event on window with e.preventDefault(). deltaY > 0 → goTo(active+1), < 0 → goTo(active-1). Must call addEventListener('wheel', fn, {passive:false}).hooks/useScrollSection.js
Transition logic: outgoing panel → gsap.to(outEl, {y:'-100%', opacity:0, scale:0.95, duration:0.85, ease:'power3.inOut'}). Incoming panel → gsap.fromTo(inEl, {y:'100%',opacity:0,scale:0.97}, {y:0,opacity:1,scale:1,...}). Run both simultaneously.hooks/useScrollSection.js
ScrollProgress.jsx: 5 vertical pills (right edge, fixed). Active pill fills with teal. Add touch event handlers (touchstart/touchend) for mobile swipe. Disable wheel hijack on pointer: coarse devices.components/ScrollProgress.jsx
